🧠💬 Context-Aware QA Chatbot (GEN-AI)

⚡ A blazing-fast Generative AI QA Chatbot that remembers previous conversations, built with Streamlit, Python, and Groq LLM (YES, it’s FREE 😎).

This chatbot uses conversation memory to provide context-aware responses, making interactions feel natural, intelligent, and human-like.

🚀 Features

🔥 Remembers Previous Context
🧠 Conversation Memory (Chat History)
⚡ Ultra-Fast Inference using Groq LLM
🎨 Clean & Interactive Streamlit UI
🔗 Single App = Frontend + Backend
💸 Completely Free LLM (Groq)
